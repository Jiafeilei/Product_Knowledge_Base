# BETAFPV Flysky RX2A Pro Receiver for Micro Drone(Upgraded)

## 产品介绍

The FS-RX2A has been upgraded, which is an AFHDS 2A compatible receiver in a minuscule form factor. Weighing only 0.88g, this receiver is perfect for micro builds.

This is also the stock receiver for BETAFPV BNF Flysky version drones.

### Specification

- RF Range: 2.408-2.475GHZ

- RX Sensitivity: -92dBm

- 2.4GHz protocol: AFHDS 2A

- Signal output: S.BUS output (3.3V high-level signal, well compatible with most F1, F3, F4, F7 FC)

- Antenne length: 33mm

- Power input: 4.0V~6.0V

- Control distance: 400m+

- Current: 30MA

- Size: 10*16.6mm

- Weight: 0.88g

- High-performance discrete LNA chip

- Compatible Transmitter: All AFHDS 2A Transmitter, for example, FS-I6, FS-I6X, FS-I6S, FS-TM8, FS-TM10, FS-I10, and Turnigy Evolution, etc.

### Package

- 1 * Flysky RX2A Pro Receiver
