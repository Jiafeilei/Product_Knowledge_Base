# BETAFPV Beta65S BNF Micro Whoop

## 产品介绍

(old version) Beta65S with 7x16mm brushed motors have upgraded F4 Brushed FC with M01 AIO Camera 5.8G VTX. The table below shows the FC and RX that come with the drone according to the version you choose. Please note the SPI Frsky RX is the FCC version.

Note: There are some changes to the Beta65S BNF Micro Whoop Quadcopter. First, the new F4 1S AIO flight controller uses MPU6500 gyro instead of MPU6000 gyro. BT2.0 battery and cable take the place of PH2.0. Finally, the Frsky protocol version is modified from Frsky FCC to Frsky D8.

Note: If you are a Spektrum DXe radio transmitter or OrangeRX RF module user and find that you can't bind successfully, please create a ticket to contact us.

### Bullet Point

- The latest Beta65S has been updated with the newest canopy which is more durable.

- More punch on the throttle with faster 19000KV 7x16mm motors and 3-blade propellers.

- A great alternative to the popular regular whoop drone.

- Provide 3 receiver versions for choice, including SPI Frsky Rx, DSMX Rx, SPI FUTABA Rx, and Flysky Rx.

- BETAFPV M01 AIO VTX camera with 48 channels in total.

### Specification

- Frame: 65s frame V4

- Weight: 25g (without battery)

- Flight Controller: BETAFPV F4 Brushed FC / F4 Brushed NO RX FC /  F3 Flysky FC / F4 Brushed FC (DSMX RX)

- Motor: 7x16mm Coreless Brush Motor, 19000KV

- Receiver: SPI Frsky D16 protocol / SPI FUTABA RX / SPI Flysky RX /  Native DSMX RX

- Cam: M01 AIO Camera 5.8G VTX

- Canopy: Canopy for micro camera / Canopy for Micro Camera 2022

- Power connector: JST-PH 2.0 connector, AKA PowerWhoop connector (old version) / BT2.0 connector, BT2.0-PH2.0 Adapter Cable, BT2.0 1S Whoop Cable Pigtail (new version)

- Battery: 300mAh 1S Lipo Battery/ BT2.0 300mAh 1S 30C Battery (old version) / BT2.0 300mAh 1S 75C Battery(new version)

- Propeller: HQ 31mm 3-Blade Propellers (0.8mm Shaft 4PCS)

- Flight time: 3 min 30 second

Note: The battery will be upgraded from BT2.0 300mAh 1S 30C Battery to BT2.0 300mAh 1S 75C Battery from Feb 2024.
