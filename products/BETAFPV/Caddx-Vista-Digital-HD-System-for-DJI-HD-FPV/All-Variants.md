# BETAFPV Caddx Vista Digital HD System for DJI HD FPV

## 产品介绍

The Caddx Vista Air Module is finally ready. Smaller and lighter than the original DJI Air Unit. Supports original DJI FPV Goggles and DJI FPV Remote Controller.
For more details, please check the Caddx official website.

### Know More

The unit has single antenna output, no on-board DVR recording.

High recommend the BETAFPV mini canopy and the 95X frame for this unit.

### Specification

- Item: Caddx Vista Camera

- Vista Kit(camera included):29g

- Antenna: 3.5g

- Dimensions: Vista Unit: 30mm x 29mm x 13mm

- Camera: 27.4mm x 21.1mm x 20.1mm

- Coaxial Cable: 80mm

- Operating Frequency: 5.725GHz- 5.850GHz

- Transmitter Power(EIRP): FCC/SRRC/MIC: <30dBm CE:<14dBm

- Min.Latency(end-to-end): Low Latency Mode(720 120fps) 21-28ms;

- High Quality Mode(720 60fps) 30-40ms;

- Max. Transmission Distance: FCC/SRRC: 4km; CE: 0.7km

- I/O Interface : USB-C, U.FL, 3-in-1 port

- Support Flight Controller system: Betaflight

- Operating Temperature Range: 32° to 104°F(0° to 40°C)

- Input power 7.4-26.4V

- DJI Camera: Sensor: 1/3.2'' CMOS Effective Pixels: 4M Lens:2.1mm,f/2.1

- Shutter: Rolling shutter. ISO: 100-25600 FOV:150°D 122°H 93°V

- Support DJI Goggle and Remote controller
