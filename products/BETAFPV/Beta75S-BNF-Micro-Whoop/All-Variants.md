# BETAFPV Beta75S BNF Micro Whoop

## 产品介绍

Beta75S BNF Micro Whoop Quadcopter is discontinued now. If you are interested in the Brushed Series drone, welcome to try the Beta65S Whoop Quadcopter.

Beta75S all versions have upgraded F4 Brushed FC with M01 AIO Camera 5.8G VTX. The table below shows the FC and RX that comes with the drone according to the version you choose.

Note: The SPI Frsky RX is FCC version.

The Beta75S has 2 improvement based on Beta75 drones.

- Motors: 7x20mm -> 8x20mm brushed motors

- Battery: 260mAh -> 550mAh Lipo HV battery

The Beta75S was crested based on the designs of the BETAFPV Team, Harley Finberg and Myles Myers.

Thanks for Quadcopter 101 channel  work on the review of Beta75. You could also find more videos about BETAFPV drones on Youtube. The testing video for Beta75S will come soon.

Tip: If you are Spektrum DXe radio transmitter or OrangeRX RF module users and find that you can't bind successfully, please create a ticket to contact us.

### Bullet Point

- Great alternative to popular Whoop Drone.

- More punch on throttle with 8x20mm motors and 3-blade 40mm propellers.

- The same hole pattern with Whoop Drone flight controller

### Specification

- Wheelbase: 75mm

- Weight: 38g (without battery)

- Flight Controller: BETAFPV Brushed FC with OSD

- Firmware Version: Betaflight BETAFLIGHTF3 3.5.0 / Betaflight MATEKF411RX 3.5.0

- Motor: 8x20mm coreless brushed motor, 15000KV

- Receiver:SPI Frsky D16 potocol / SPI FUTABA RX / SPI Flysky RX / Native DSMX RX

- M01 AIO Camera 5.8G VTX

- Batterry: 550mAh Lipo HV battery

- Flight time: 5 minutes

### Assembly Parts List

- Frame: Beta75S frame

- Motors: 8x20mm brushed motors

- Props: 40mm 3-blades props / 40mm 4-blades props

- FC: F4 Brushed FC / F4 Brushed No RX FC /  F3 Flysky FC /  F4 Brushed FC (DSMX RX)

- M01 AIO Camera 5.8G VTX

- Battery: 550mAh LiHV battery
