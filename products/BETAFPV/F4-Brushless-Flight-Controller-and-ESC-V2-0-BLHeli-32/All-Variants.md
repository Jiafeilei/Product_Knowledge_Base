# BETAFPV F4 Brushless Flight Controller and ESC V2.0 (BLHeli_32)

## 产品介绍

After several months of research, the greatest combination of F405 4S Brushless Flight Controller with BLHeli_32 16A ESC has been released which totally supports 4S power with a steady performance. BLHeli_32 16A ESC is customized for Beta85X whoop drone. Meanwhile, Beta85X is the first micro drone with a BLHeli_32 ESC at present.

BLHeli_32 is the 3rd generation ESC firmware after BLHeli and BLHeli_S, which is written for ESC's that utilize 32-bit MCU. With the increase in processing power, faster input signals with lower latency and higher update rate would be possible in BLHeli_32, such as Dshot1200!

Know more about BLHeli_32 ESC from Oscarliang's blog.

Check out Joshua Bardwell's video to know every detail of BLHeli_32

### SPECIFICATIONS OF FC

- CPU: STM32F405 (Overclock to 240MHz)

- Six-Axis: MPU6000

- Size: 26mm x 26mm, whoop mounting pattern

- Firmware version: BETAFPVF405 (BEFH)

- OSD: Built-in BetaFlight OSD (STM32 controls OSD chip over SPI in DMA mode)

- RX3 and TX3 are with auto inverter, supporting all RX including TBS Micro RX

- TX01 and RX01 ports are available for Frsky F-Port, DSM2/DSMX

- Buzzer solder pads

- Support programable LED like WS2812 etc

- Weight: 4.2g

### SPECIFICATIONS OF ESC

- Support BLHELI_32

- Support PWM, Oneshot125, Oneshot42, Multishot, Dshot150, Dshot300, Dshot600, Dshot1200

- Input voltage: 3-4S lipo

- Cotinue current: 16A

- Peak current: 19A

- Firmware target: BETAFPV-16A-32bit

- MCU: STM32F051K66

- Motor Connectors: 1.25mm header pins connector

- Weight: 4.4g (7.7g with XT30 cable)

### PARTS UPDATED

- F405 4S FC board has added extra 4 pluggable ports for ESC, VTX, RX and LED board, convenient installation and decreasing the dislocated PIN mounting.

- Using single N-channel MosFETs on ESC board, which has a lower inner resistance. It is dual MosFETs on the original BLHeli_32 ESC board. Current sensor included.

-
BLHeli_32 ESC is soldering with 25V/220uf electrolytic capacitor, for reducing the defective rate caused by the instantaneous high voltage.

### HOW TO ASSEMBLE FC & ESC

In order to be convenient for the installation and decrease the dislocated PIN mounting, we have added a port for ESC connection. Separate installation, in case the mutural vibration may interfere between FC and ESC.

### HOW TO ASSEMBLE FC & LED BOARD
