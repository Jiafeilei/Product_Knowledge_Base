# BETAFPV BETAFPV LED Board (2PCS)

## 产品介绍

Do you guys still remember the Argonay FPV Session Reimagined with the Beta75X made by Team Props Out? In that reimaginating video of FPV Racing - Crash Session, the members from the Team Props Out fly BETA75X to show respect for the original video and to inspire more people join FPV community.

Just a few months passed since the release of BETA75X, we are excited to announce that the LED board and the V1.2 F4 2S Brushless FC are on sales now. You can now make your flying just as amazing as Team Props Out do. The LED board can ONLY fit on BETA75X frame at the moment.

### SPECIFICATION

- LED: WS2812B-5050

- Size: 23.5mm × 11.4mm

- Voltage: 3.3～5.2V DC

- Support: Betaflight / Cleanflight

- Frame: Beta 75X

- Weight: 1.0g

- Wire Material: Silicone wire coated with tin

- Wire Length: 65mm

- Wire Color: Red, Yellow, Black

### HOW TO CONNECT LED BOARD TO FC

V1.1 Version

Go to the CLI tab in Betaflight GUI and copy all the commands below to enable the LED_STRIP, but the TX1 port will be invalid.

resource SERIAL_TX 1 NONE

resource LED_STRIP 1 NONE

resource LED_STRIP 1 A09

save

If the LED still doesn’t work when you set LED_STRIP, please put your FC in DFU mode and reflash. Note that the 5v pad on the led strip can be soldered on the +5v or the Buzz+ of the FC (see diagram).

V1.2 Version

Note that the 5v pad on the led strip can be soldered on the +5v or the Buzz+ of the FC (see diagram).

### How to SET UP LED on Betaflight

1.Enable LED Strip in Configuration Tab and click the Save and Reboot button in the lower right corner.

2.Click Wire Ordering Mode

3.You can start to choose the color of the LED now.

Note: You should start to choose the color from the top left corner first otherwise you will fail to set up the color. Don't forget to save all of your setting after you make all of the changes.
