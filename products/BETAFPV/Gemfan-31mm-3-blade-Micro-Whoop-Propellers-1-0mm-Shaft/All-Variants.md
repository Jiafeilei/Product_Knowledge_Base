# BETAFPV Gemfan 31mm 3-blade Micro Whoop Propellers (1.0mm Shaft)

## 产品介绍

These 31mm props are just customed for 65mm brushless drones that has 1.0mm motor shaft. The recommended motor is 0603 motor, and 080X motor like 0802 motor. Here is the 31mm 4-blade props (1.0mm Shaft) for your choice.

### Specification

- Item: 31mm 3-blade Props

- Blades: 3

- Material: PC (Poly Carbonates)

- Center Thickness: 5mm

- Prop Disk Diameter: 31mm

- Mounting hole: 1.0mm shaft

- Max Prop Width: 5.71mm

- Weight (2CW+2CCW): 1g

- Color: White / Black / Blue / Yellow / Purple / Clear Blue

### Recommended Parts

- Drone: Beta65X HD/ Beta65 Pro 2 / Beta65 Pro / Meteor65

- Frame: Beta65 Pro frame / Beta65X 2S frame / Meteor65 frame

- Motor: 0603 motors /  0703 motor / 0802 motor

### Package

- 2 * CW 31mm 3-blade Micro Whoop Propellers (1.0mm Shaft)

- 2 * CCW 31mm 3-blade Micro Whoop Propellers (1.0mm Shaft)
