# BETAFPV Beta75 Pro 2 Whoop Frame

## 产品介绍

This Beta75 Pro 2 frame is customized for Beta75 Pro 2 whoop drone.

- Light enough: only weighs 5.5g.

- Battery slot is suitable for both 1S & 2S battery.

By default, with the help of foam adaptor, the battery slot is designed for 2pcs 300mAh Lipo HV 1S whoop style battery.

- Motor mounting holes fit multiple types of motors.

The motor mounting holes on the Beta75 Pro 2 frame are suitable for BETAFPV's 0802 / 0703 / 0603 brushless motors. Thus, the frame can be used on Pro2 Series drones and 1S Pro Series (65pro/75pro).

### Specification

- Material: Clear plastic

- Diagonal motor to motor distance: 75mm

- Motor mounting hole: for 0802 12000KV  motors

- FC mounting hole: fully compatible with whoop style FC board mounting pattern, 26mm x 26mm

- Battery slot size: 11.5x16mm, for BETAFPV 300mAh 1S battery

- Weight: 5.5g

### Recommended Parts

- Propellers: 40mm 4-blade propeller (1.0mm shaft hole)

- Motors: 0802 12000KV Motors

- Batteries: BETAFPV 300mah 1S battery 2 pcs

- FC & ESC: F4 2S AIO Flight Controller and ESC

### Package

This plastic durable package can protect the package from deformation during the shipping process.
