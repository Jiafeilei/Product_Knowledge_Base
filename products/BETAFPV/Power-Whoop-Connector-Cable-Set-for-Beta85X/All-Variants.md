# BETAFPV Power Whoop Connector Cable Set for Beta85X

## 产品介绍

This connector cable set is customized for F4 V2 4S FC and BLHeli_32 ESC. Convenient for installation with ESC, RX, LED board and camera on Beta85X 4S Whoop Drone.

### Bullet point

- Optimize the connection with the F4 V2 4S FC , reducing the solder process. Easy to change the camera to the EOS2, Turtle V2 or Tarsier 4K on the Beta85X.

- This cable set is included 3-pin led board cable, 4-pin receiver cable, 7-pin ESC cable, 7 to 5-pin EOS camera cable, Caddx turtle V2 camera cable, Tarsier 4K camera cable.

- As a spare power whoop connector cable for DIY Beta85X 4S whoop.

### Recommend Parts

- Adapt FC: F4 4S FC V2.0

- Adapt ESC : BLHeli_32 ESC

- Adapt Receiver: Frsky XM+ / DSMX / Futaba S-FHSS / Flysky / TBS Crossfire

- Adapt LED: BETAFPV LED Board

- Adapt Camera: EOS2, Turtle V2 and Tarsier 4K Camera

- Adapt Drone : Beta85X 4S, Beta85X HD, Beta85X 4K.
