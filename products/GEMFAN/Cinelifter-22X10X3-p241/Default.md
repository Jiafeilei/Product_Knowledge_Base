# GEMFAN Cinelifter 22X10X3三叶-玻纤尼龙

## 产品介绍

GEMFAN 22×10×3 大载重运输型螺旋桨
乾丰22×10×3三叶螺旋桨专为轻小型多轴无人机运输场景打造，是GEMFAN大载重螺旋桨系列的重要成员。22英寸大直径配合10英寸螺距，适配25kg级起飞重量，为物流配送、应急运输、农业植保等大负载作业场景提供充沛持久的动力输出。
产品采用高强度玻纤尼龙材质，兼顾结构刚性、韧性与轻量化需求。高精密动平衡制造工艺贯穿全流程，确保每一支螺旋桨在高转速、大负载工况下保持低振动运转，为飞行平台提供稳定可靠的推力支持，保障任务执行的平稳性与安全性。
中心孔径提供4mm / 15-M3 / 20-M4三种规格，适配多种电机安装需求，兼容性强，安装便捷。推荐搭配7218电机，充分发挥大载重平台的动力潜能。
