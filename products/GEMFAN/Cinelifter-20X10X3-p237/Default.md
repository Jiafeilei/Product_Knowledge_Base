# GEMFAN Cinelifter 20X10X3三叶-玻纤尼龙

## 产品介绍

GEMFAN 20×10×3 重载运输型螺旋桨
专为重载运输与工业级无人机平台打造，20×10×3采用三叶设计，20英寸大直径配合10英寸螺距，适配16kg级（四轴）起飞重量，为物流配送、农业植保、测绘巡检等重载作业场景提供充沛持久的动力输出。
产品采用8mm中心孔径 + 六孔适配圈安装方式，兼容多种电机平台，安装便捷可靠。生产环节采用全检方式出货，每一支螺旋桨均经过严格性能与动平衡检测，确保批次一致性与飞行稳定性。
上下桨毂特殊槽位设计，可与电机厂家配合实现螺旋桨防滑锁定，有效防止高负载工况下的打滑位移，为大载重飞行提供额外安全保障。
推荐搭配6215 180kv电机（12S），充分发挥重载平台的动力潜能。
