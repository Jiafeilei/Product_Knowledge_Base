# GEMFAN FURY 5131 .0 三叶-PC

## 产品介绍

Gemfan Fury 5131.0 是 Fury 系列推出的一款 5.1 英寸竞速螺旋桨。其设计旨在匹配高KV电机，以期实现较快的响应与加速表现，并为飞行提供顺滑的操控体验。
此桨叶作为 Fury 系列的新型号，在开发中考虑了竞速飞行对动力响应的需求。其设计目标之一是尝试兼顾类似 MCK V2 的动力输出特性与 MCK V3 的操控精度。
型号 Fury 5131.0，桨盘直径 129mm，螺距 3.1英寸。单支重量 4.2g，采用 PC 材质。中心厚度 6.7mm，桨叶宽度 15mm。中心孔径 5mm。
